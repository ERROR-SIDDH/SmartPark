# Administrative Control Systems (Admin Portal)

The Admin Portal serves as the primary management interface for overseeing parking logistics. It is designed to provide comprehensive control over facility configuration and user administration.

### Parking Facility Configuration
The system allows administrators to define the physical parameters of the parking lot:
- **Layout Integration**: Administrators can upload architectural diagrams or aerial imagery of the facility to serve as a base layer.
- **Vector-Based Slot Mapping**: An interactive drawing utility enables the precise placement and labeling of parking slots.
- **Specification Management**: Administrators can designate specific slots for various vehicle classifications, including standard passenger vehicles, motorcycles, and Electric Vehicles (EVs).

### Analytical Oversight
The dashboard provides a high-level overview of facility metrics, facilitating data-driven decision-making:
- **Occupancy Metrics**: Real-time analysis of current lot utilization.
- **Live Monitoring**: A dynamic map reflecting the current state of every parking slot.
- **Scheduling Logs**: Access to comprehensive booking records and upcoming reservations.

### Personnel Administration
The portal facilitates the management of user accounts, supporting bulk data importing via standardized file formats. Administrators maintain the authority to manage credentials, adjust access levels, and resolve scheduling conflicts as they arise.
